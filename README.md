# Maxikiosco La 79

    npm install
    npm run dev

- Textos, teléfono y links: `src/data.js`
- Imágenes: poné los archivos en `public/img/` y completá el campo `img` en `src/data.js` (ej: `"/img/bebidas.jpg"`).
  La imagen principal y la del mapa se pasan con `src` en `src/App.jsx`.
- Estilos (styled-components): `src/styles.js` y colores en `src/GlobalStyle.js`.
